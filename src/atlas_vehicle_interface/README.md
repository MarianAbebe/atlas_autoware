# atlas_vehicle_interface

Atlas drivetrain integration with Autoware.

Scaffold only; no robot functionality is implemented.

## Intended responsibilities

- Interface between Autoware control commands and the Atlas drivetrain.
- Vehicle status feedback to Autoware.
